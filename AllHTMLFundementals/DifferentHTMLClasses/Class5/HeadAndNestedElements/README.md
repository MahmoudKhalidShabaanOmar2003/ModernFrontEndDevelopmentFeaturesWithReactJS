# 04)**Head , And Nested Elements:
<p align="justify">04.1)**&lt;HEAD&gt;: It Is A Nested HTML Tag , It Refers To The Head Of Your Own HTML Document , It Represents A Collection Of MetaData For Your Own HTML Document (Own Web Page) To Know Different Browsers Like Google Chrome , Firefox Developer Edition , Or ETC How To Archive , Or Render Your Own HTML Document (Own Web Page)...&lt;/HEAD&gt;</p>

--------------------------------------------------------------------

<p align="justify">04.2)**MetaData: It Is A Collection Of Instructions , Or Information About Information For Your Own HTML Document (Own Web Page) To Know Different Browsers Like Google Chrome , Firefox Developer Edition , Or ETC How To Archive , Or Render Your Own HTML Document (Own Web Page) , And If You Want To Add Different Types Of MetaData , You Must Use &lt;META /&gt;</p>

--------------------------------------------------------------------

<p align="justify">04.3)**<META />: It Is A Self-Closing Tag , Void Tag , Or Empty Tag , It Is Mainly Used To Add Different MetaData For Your Own HTML Document (Own Web Page) To Know Different Browsers Like Google Chrome , Firefox Developer Edition , Or ETC How To Archive , Or Render Your Own HTML Document (Own Web Page) , Different MetaData Does Not Appear For Different Users Of Your Own HTML Document (Own Web Page)...</p>
<p align="justify"><strong>04.4)**There Are Different Types Of HTML Attributes That Should Use Inside &lt;META /&gt; HTML Tag Like:</strong></p>
  
  - <p align="justify">04.4.1)**Name: It Is A Global HTML Attribute , It Is Mainly Used To Add The Name Of The MetaData...</p>
  
  - <p align="justify">04.4.2)**Content: It Is A Global HTML Attribute , It Is Mainly Used To Add The Content Of The MetaData...</p>
  
  - <p align="justify">04.4.3)**Charset: It Is An Element HTML Attribute , It Refers To Character Set , It Refers To A Specific Characters That Mainly Used In Your Own HTML Document...</p>

  --------------------------------------------------------------------------------
<p align="justify"><Strong>04.5)**There Are Different Types Of The MetaData Like: </Strong></p>  

------------------------------------------------------------------------

  - <p align="justify">04.5.1)**&lt;META name="description" content="It The Is Description For Your Own HTML Document (Own Web Page)..." /&gt;:</p>
  
    - <p align="justify">04.5.1.1)**It Is Mainly Used To Add The Description For Your Own HTML Document (Own Web Page) To Know Different Browsers Like Google Chrome , Firefox Developer Edition , Or ETC How To Archive , Or Render Your Own HTML Document (Own Web Page)...</p>
    
    - <p align="Justify">04.5.1.2)**It Does Not Appear For Different Users Of Your Own HTML Document (Own Web Page)...</p>
    
    - <p align="justify">04.5.1.3)**It Appears In The View Page Source Of Your Own HTML Document (Own Web Page)...</p>
    
    - <p align="justify">04.5.1.4)**It Appears In The Searching Result About Your Own HTML Document (Own Web Page) In Different Browsers Like Google Chrome , Firefox Developer Edition , Or ETC...</p>
    
    - <p align="justify">04.5.1.5)**It Makes Your Own HTML Document (Own Web Page) SEO Friendly (This Means Appearing In The Frist Searching Results In Different Browsers Like Google Chrome , Firefox Developer Edition , Or ETC...</p>

-----------------------------------------------------------------------

  - <p align="justify">04.5.2)**&lt;META name="keywords" content="Own HTML Document , Own , HTML , Document" /&gt;:</p>
  
    - <p align="justify">04.5.2.1)**It Is Mainly Used To Add Different Keywords For Your Own HTML Document (Own Web Page) To Know Different Browsers Like Google Chrome , Firefox Developer Edition , Or ETC How To Archive , Or Render Your Own HTML Document (Own Web Page)...</p>
    
    - <p align="justify">04.5.2.2)**It Does Not For Different Users Of Your Own HTML Document (Own Web Page)...</p>
    
    - <p align="justify">04.5.2.3)**It Appears In The View Page Source Of Your Own HTML Document (Own Web Page)...</p>
    
    - <p align="justify">04.5.2.4)**It Makes Your Own HTML Document (Own Web Page) SEO Friendly (This Means Appearing In The Frist Searching Results In Different Browsers Like Google Chrome , Firefox Developer Edition , Or ETC...</p>

--------------------------------------------------------------------------------

  - <p align="justify">04.5.3)**&lt;META name="author" content="Mahmoud Khalid Shabaan Omar..." /&gt;:</p>
  
    - <p align="justify">04.5.3.1)**It Is Mainly Used To Add The Name Of The Author Of Your Own HTML Document (Own Web Page)...</p>
    
    - <p align="justify">04.5.3.2)**It Does Not Appear In Your Own HTML Document (Own Web Page) While Archiving , Or Rendering Your Own HTML Document (Own Web Page) In Different Browsers Like Google Chrome , Firefox Developer Edition , Or ETC...</p>

    ------------------------------------------------------------------------------
    
  - <p align="justify">04.5.4)**&lt;META name="developer" content="Mahmoud Sallam..." /&gt;:</p>
  
    - <p align="justify">04.5.4.1)**It Is Mainly Used To Add The Name Of The Developer Of Your Own HTML Document (Own Web Page)...</p>
    
    - <p align="justify">04.5.4.2)**It Does Not Appear In Your Own HTML Document (Own Web Page) While Archiving , Or Rendering Your Own HTML Document (Own Web Page) In Different Browsers Like Google Chrome , Firefox Developer Edition , Or ETC...</p>

    ------------------------------------------------------------------------------
    
  - <p align="justify">04.5.5)**&lt;META name="viewport" content="width=device-width , initial-scale=1.0" /&gt;:</p>
  
    - <p align="justify">04.5.5.1)**It Is Mainly Used To Set The Dimenssion That Makes Your Own HTML Document (Own Web Page) Responsive In Different Screens While Using Any CSS Libraries Like BootStrapCSS , Or TailwindCSS...</p>
    
    - <p align="justify">04.5.5.2)**It Does Not Appear For Different Users Of Your Own HTML Document (Own Web Page)...</p>
    
-----------------------------------------------------------------------------------------------

  - <p align="justify">04.5.6)**&lt;META charset="ISO-8859-1" /&gt;:</p>

    - <p align="justify">04.5.6.1)**It Is Mainly Used To Define A Specified Characters Set That Mainly Used For Your Own HTML Document (Own Web Page)...</p>
    
    - <p align="justify">04.5.6.2)**It Does Not Support The Arabic Language , It Only Supports English Language In Your Own HTML Document (Own Web Page)...</p>

------------------------------------------------------------------------------------------------------

- <p align="justify">04.5.7)**&lt;META charset="UTF-8" /&gt;:</p>

  - <p align="justify">04.5.7.1)**It Is Mainly Used To Define A Specific Characters Set That Mainly Used For Your Own HTML Document (Own Web Page)....</p>

  - <p align="justify">04.5.7.2)**It Supports Both English Language , And Arabic Language In Your Own HTML Document (Own Web Page)...</p>
  
------------------------------------------------------------------------------------------------------

  - <p align="justify">04.5.8)**&ltMETA name="robots" content="follow , index" /&gt;:</p>
  
    - <p align="justify">04.5.8.1)**This Meta Is Used To Allow Your Own HTML Document (Own Web Page) To Follow Different Links...</p>
    
    - <p align="justify">04.5.8.2)**This Meta Is Used To Make Your Own HTML Document (Own Web Page) To Appear In The Frist Searching Results In Different Browsers Like Google Chrome , Firefox Developer Edition , Or ETC...</p>

-----------------------------------------------------------------------------------------------

> You Must Know That Different MetaData Does Not Appear For The User Of Your Own HTML Document (Own Web Page)...

<p align="justify">04.7)**&lt;STYLE&gt;: It Is A Nested HTML Tag , It Is Mainly Used To Add Different Internal CSS Styling Codes , Or Internal CSS Decorations Codes For Your Own HTML Document (Own Web Page)...&lt;/STYLE&gt;</p>

  - <p align="justify">04.7.1)**Different CSS Styling Codes , Or CSS Decorations Codes Do Not Appear For Your Own HTML Document (Own Web Page)... But It Mainly Used By Different Browsers Like Google Chrome , Firefox Developer Edition But It Is Mainly Used To Make The Styling , Or Decorations Of Your Own HTML Document (Own Web Page)...</p>
