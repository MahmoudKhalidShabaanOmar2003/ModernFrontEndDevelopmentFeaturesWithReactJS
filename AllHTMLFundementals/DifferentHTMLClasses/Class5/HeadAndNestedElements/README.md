# 04)**Head , And Nested Elements:
<p align="justify">04.1)**&lt;HEAD&gt;: It Is A Nested HTML Tag , It Refers To The Head Of Your Own HTML Document , It Represents A Collection Of MetaData For Your Own HTML Document (Own Web Page) To Know Different Browsers Like Google Chrome , Firefox Developer Edition , Or ETC How To Archive , Or Render Your Own HTML Document (Own Web Page)...&lt;/HEAD&gt;</p>
<p align="justify">04.2)**MetaData: It Is A Collection Of Instructions , Or Information About Information For Your Own HTML Document (Own Web Page) To Know Different Browsers Like Google Chrome , Firefox Developer Edition , Or ETC How To Archive , Or Render Your Own HTML Document (Own Web Page) , And If You Want To Add Different Types Of MetaData , You Must Use &lt;META /&gt;</p>
<p align="justify">04.3)**<META />: It Is A Self-Closing Tag , Void Tag , Or Empty Tag , It Is Mainly Used To Add Different MetaData For Your Own HTML Document (Own Web Page) To Know Different Browsers Like Google Chrome , Firefox Developer Edition , Or ETC How To Archive , Or Render Your Own HTML Document (Own Web Page) , Different MetaData Does Not Appear For Different Users Of Your Own HTML Document (Own Web Page)...</p>
<p align="justify"><strong>04.4)**There Are Different Types Of HTML Attributes That Should Use Inside &lt;META /&gt; HTML Tag Like:</strong></p>
  
  - <p align="justify">04.4.1)**Name: It Is A Global HTML Attribute , It Is Mainly Used To Add The Name Of The MetaData...</p>
  
  - <p align="justify">04.4.2)**Content: It Is A Global HTML Attribute , It Is Mainly Used To Add The Content Of The MetaData...</p>
  
  - <p align="justify">04.4.3)**Charset: It Is An Element HTML Attribute , It Refers To Character Set , It Refers To A Specific Characters That Mainly Used In Your Own HTML Document...</p>
